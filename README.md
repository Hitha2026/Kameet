# Pong Network Arena — الإصدار 2.1

لعبة ويب عربية تجمع بين **Pong** و **Breakout**، وتدعم الذكاء الاصطناعي والمباريات الخاصة والمطابقة العشوائية بين المستخدمين.

## الجديد في الإصدار 2.1

- إضافة تشكيل طوب علوي وتشكيل سفلي مقابل له داخل الملعب.
- تطبيق التشكيل المتناظر في اللعب ضد الذكاء الاصطناعي وفي المباريات الأونلاين.
- يبدأ المستوى الأول بـ48 طوبة: 24 في الأعلى و24 في الأسفل.
- تجهيز المشروع للرفع المباشر إلى GitHub.
- إضافة GitHub Actions لفحص JavaScript ونشر مجلد `public` على GitHub Pages.
- إضافة ملف إعداد يسمح لواجهة GitHub Pages بالاتصال بخادم أونلاين خارجي.
- حماية ملف الحسابات وملفات البيئة من الرفع العرضي إلى المستودع.

## أنماط اللعب

1. اللعب محليًا ضد الذكاء الاصطناعي دون حساب.
2. اللعب مع صديق على جهاز آخر باستخدام رمز غرفة خاص.
3. المطابقة السريعة مع أي مستخدم متصل.
4. إنشاء حساب وتسجيل الدخول وحفظ الفوز والخسارة.
5. تثبيت اللعبة كتطبيق ويب PWA على الكمبيوتر أو الهاتف.

## البنية التقنية

- الواجهة: HTML5 + CSS3 + JavaScript Canvas.
- الخادم: Node.js + Express.
- الاتصال اللحظي: Socket.IO.
- الحسابات: JWT مع تشفير كلمات المرور بواسطة bcryptjs.
- المباراة الأونلاين: الخادم هو المصدر المعتمد لحركة الكرة والنتيجة والطوب.

## التشغيل الكامل على Windows

شغّل:

```text
START_WINDOWS.bat
```

أو نفّذ يدويًا:

```bash
npm install
npm start
```

ثم افتح:

```text
http://localhost:3000
```

## اللعب مع صديق على شبكة Wi-Fi نفسها

1. شغّل الخادم على جهاز واحد.
2. اعرف عنوان IP المحلي لذلك الجهاز، مثل `192.168.1.20`.
3. افتح المنفذ 3000 في جدار الحماية عند الحاجة.
4. يفتح اللاعبان `http://192.168.1.20:3000`.
5. يسجل كل لاعب بحساب مختلف.
6. ينشئ اللاعب الأول غرفة ويرسل الرمز إلى اللاعب الثاني.

## رفع المشروع إلى GitHub

راجع الملف:

```text
DEPLOY_GITHUB_AR.md
```

يمكن في Windows تشغيل:

```text
UPLOAD_TO_GITHUB.bat https://github.com/USERNAME/REPOSITORY.git
```

## GitHub Pages

Workflow النشر موجود في:

```text
.github/workflows/pages.yml
```

نسخة GitHub Pages تشغّل وضع الذكاء الاصطناعي مباشرة. لتفعيل التسجيل والغرف والمطابقة الأونلاين، انشر `server.js` على استضافة Node.js تدعم WebSocket وHTTPS، ثم ضع رابط الخادم في:

```text
public/config.js
```

مثال:

```javascript
window.PONG_CONFIG = Object.freeze({
  serverUrl: "https://your-pong-server.example.com"
});
```

GitHub Pages لا يشغّل خادم Node.js نفسه؛ لذلك يبقى الخادم الخلفي مطلوبًا للعب بين مستخدمين حقيقيين.

## متغيرات البيئة

انسخ `.env.example` إلى `.env` محليًا، واضبط:

```text
PORT=3000
JWT_SECRET=قيمة_طويلة_وعشوائية
ALLOWED_ORIGIN=https://USERNAME.github.io
NODE_ENV=production
```

يمكن السماح بأكثر من Origin بفصلها بفاصلة.

## Docker

```bash
docker compose up --build -d
```

## الملفات الأساسية

- `server.js`: الحسابات والغرف والمطابقة ومحرك المباراة الأونلاين.
- `public/app.js`: اللعب المحلي والرسم والاتصال بالخادم.
- `public/config.js`: رابط الخادم عند فصل الواجهة عن الخلفية.
- `.github/workflows/ci.yml`: فحص المشروع بعد كل Push أو Pull Request.
- `.github/workflows/pages.yml`: نشر الواجهة على GitHub Pages.
- `DEPLOY_GITHUB_AR.md`: دليل الرفع والنشر بالعربية.
- `UPLOAD_TO_GITHUB.bat`: رفع سريع من Windows.

## ملاحظات أمنية

- لا ترفع ملف `.env` إلى GitHub.
- لا تضع مفتاح `JWT_SECRET` الحقيقي داخل الكود.
- ملف `data/users.json` مستبعد من Git ويُنشأ تلقائيًا عند تشغيل الخادم.
- استخدم HTTPS عند نشر التسجيل واللعب الأونلاين.
